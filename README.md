# BunnyMate

Cara pakai: ekstrak zip ini lalu klik dua kali `index.html` (tanpa install apa pun).

- `fuzzy.js`  : perhitungan Fuzzy Tsukamoto 
- `app.js`    : tampilan, data kelinci, rencana kawin
- `style.css` : tampilan
- `index.html`: kerangka halaman

Data tersimpan di localStorage browser. Untuk reset: hapus data situs di browser.
